# 🪑 Furniture Store Template

A responsive furniture e-commerce landing page built with **pure HTML and CSS**, as part of my Computer Science studies at Karary University.

## ✨ Features

- Navbar with animated hover borders and multi-column dropdown menus
- Hero banner with slider dots
- Special categories grid with hover arrow effect
- Testimonial and discount banners with zoom effect
- Services section using a CSS sprite image
- Featured products grid with hover overlay (wishlist, quick view, compare, cart)
- Blog section and footer
- Fully responsive (desktop, tablet, phone) using media queries

## 📱 Responsive Breakpoints

| Device  | Breakpoint       | Layout                              |
|---------|------------------|-------------------------------------|
| Desktop | > 991px          | Full layout                         |
| Tablet  | max-width: 991px | 2-column grids, navbar below logo   |
| Phone   | max-width: 575px | Single column, scrollable navbar    |

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables, Media Queries)
- [Font Awesome 6](https://fontawesome.com/) for icons
- [Google Fonts](https://fonts.google.com/) (PT Sans)
